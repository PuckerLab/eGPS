The subfolder example_files contains a small test data set to run TSS_finder.

# selection.fasta
This file contains a small part of the _Arabidopsis thaliana_ TAIR10 genome sequence.

# selection.gff3
This file contains the first gene models in the _Arabidopsis thaliana_ TAIR10 annotation file.

# RNAseq_mapping_TAIR10.sample.sorted.bam
This file contains the alignment of RNA-seq reads to TAIR10. Only the region contained in the corresponding FASTA and GFF3 file is included in this BAM file.
